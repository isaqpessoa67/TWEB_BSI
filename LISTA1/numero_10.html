HTML
Linguagem de Marcação de Hipertexto. É a linguagem usada para estruturar uma página web e seu conteúdo.
CSS
Cascading Style Sheets (Folhas de Estilo em Cascata). É uma linguagem de estilo usada para descrever a apresentação visual de um documento HTML.
Javascript
Linguagem de programação interpretada. É usada para tornar páginas da web interativas e dinâmicas.
